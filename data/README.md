# data/

**アプリが実行時に使うデータ。** ここにあるものが正である。

[`docs/`](../docs/) は人が読む説明であり、**値を持たない**。
説明とデータの書き分けは [ADR-0020](../docs/adr/0020-kancolle-reference.md) による。

## なぜ `docs/` でも `src-tauri/` でもないのか

- **`docs/` ではない**: 配布物に `docs/` は入らない。実装が文書ディレクトリに依存するのは筋が悪い
- **`src-tauri/` ではない**: ここにあるのは**外部システムを観測して積み上げた知識**であり、
  ランタイムの選択（[ADR-0016](../docs/adr/0016-tech-stack.md)）より長生きする。
  Tauri をやめてもこのデータは残る

## 中身

| ディレクトリ | 内容 | 説明の在り処 |
| --- | --- | --- |
| [`kancolle/`](kancolle/) | 艦これのゲームデータ（任務テーブルなど） | [`docs/kancolle/`](../docs/kancolle/) |

## 書き方

- **各レコードに出典（`source`）と確認日（`verified`）を持たせる。**
  出典がデータと一緒に移動するようにする（[C-03](../docs/spec/constraints.md)）
- 未確認の値は `null` か `TODO(要検証)` を入れる。**推測で埋めない**
- **ビルド時に検証する。** 不正なデータでビルドが落ちること
  （[architecture.md](../docs/spec/architecture.md) の「外部データの取り込み」）
