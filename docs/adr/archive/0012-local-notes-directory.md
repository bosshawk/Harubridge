# ADR-0012: `docs/notes/` をローカル専用のメモ置き場として残す（git 管理外）

- ステータス: Superseded by [ADR-0015](../0015-documentation-layout.md)（構成に関する 6 本を統合。本文は履歴として残す）
- 日付: 2026-08-02
- 決定者: プロジェクトオーナー
- 関連: [ADR-0009](0009-notes-as-github-issues.md)（`docs/notes/` を廃止する決定を一部変更する）

## 背景と課題

[ADR-0009](0009-notes-as-github-issues.md) で、その場の方針・検討メモを GitHub Issue に移し、
`docs/notes/` を**廃止**すると決めた。捨てる資料が git 履歴に永久に残る問題を解消するためである。

しかし実際の作業では、Issue に立てるほどでもない**手元のメモ**が生じる。

- 作業中の思考の整理、コマンドの控え、読んだコードのメモ
- Issue にする前の、まだ形になっていない断片
- 共有する価値が無い、あるいは共有すべきでないもの

これらの行き場が無いと、エージェントは Issue を乱立させるか、
リポジトリ内に勝手なファイルを作る。どちらも望ましくない。

## 決定

`docs/notes/` を**ローカル専用のメモ置き場として残す**。ただし **git の管理対象外**とする。

- `.gitignore` で `docs/notes/` 配下を除外する。
  ただし `docs/notes/README.md`（この場所の説明）だけは追跡する。
- **ここに置いたものは共有されない。** 消えても困らないものだけを置く。
- **共有すべき論点は Issue に立てる。** 判断基準は「他人（将来の自分を含む）が
  読む必要があるか」。読む必要があるなら Issue、無いならここ。

[ADR-0009](0009-notes-as-github-issues.md) の本旨 ——
**捨てる資料をリポジトリの履歴に残さない** —— は維持される。
`.gitignore` により、置かれたメモはコミットされないためである。

## 検討した選択肢

### 案 A: `docs/notes/` を git 管理外で残す（採用）

- 利点: 手元のメモに定位置ができ、Issue の乱立とリポジトリ汚染の両方を防げる。
  履歴には残らないため ADR-0009 の目的と衝突しない。
- 欠点: クローンした人には見えない。エージェントが「メモを書いたのに共有されていない」
  という誤解をしうるため、**共有されないことを明示する必要がある**。

### 案 B: ADR-0009 のとおり完全に廃止する

- 却下理由: 手元のメモの行き場が無くなり、Issue の乱立か野良ファイルの生成を招く。

### 案 C: `docs/notes/` を追跡したまま残す

- 却下理由: ADR-0009 が解決した問題（捨てる資料が履歴に残る）が再発する。

## 決め手

**共有可能性を捨てて、書き捨ての自由を得た。**
書けない場所しか無いと、書くべきでない場所に書かれる。

## 影響

- `.gitignore` に `docs/notes/` の除外を追加する（`README.md` は例外）。
- 既存の論点メモ（技術構成の論点整理）は `git rm --cached` で追跡から外し、
  ローカルには残す。Issue 化はリポジトリ作成後に判断する。
- `CLAUDE.md` / `docs/README.md` / `capture-issue` スキルに、
  **「共有すべきものは Issue、手元のメモは `docs/notes/`（共有されない）」**を明記する。
- 取り消す場合のコスト: 低。
