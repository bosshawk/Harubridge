# ADR-0019: リンタに ESLint + Prettier を採用する（型情報を使ったリントを有効にする）

- ステータス: **Accepted**
- 日付: 2026-08-02
- 決定者: プロジェクトオーナー
- 関連: [ADR-0018](0018-dependencies.md)（本 ADR がリンタの選定のみを置き換える。他の依存は有効）,
  [ADR-0016](0016-tech-stack.md)

## 背景と課題

[ADR-0018](0018-dependencies.md) では `biome` を採用し、その根拠を
**「設定ファイルとツールが 1 つで済み、エージェントが誤設定する余地が減ること」**とした。

しかしこの判断は、**リンタを選ぶうえで最も重要な「何を検出できるか」を評価していなかった。**

調査の結果、次が判明した。

- Biome は速度のために **TypeScript コンパイラを使わず、独自の軽量な型合成器**を持つ設計である
- その結果、型情報を必要とするルールの検出率が typescript-eslint に届いていない。
  代表例の `noFloatingPromises`（`await` 忘れの検出）は
  **typescript-eslint が検出するケースの約 75%** に留まる。改善中だが同等ではない
- 引き換えに、50,000 行規模のプロジェクトで **10〜25 倍高速**である

**`await` 忘れは本プロジェクトで起きやすい種類のバグである。**
Rust ↔ IPC ↔ React という非同期の受け渡しが中核にあるため、
このルールが 25% 取りこぼすことの影響は小さくない。

そして [ADR-0016](0016-tech-stack.md) は
**「型で守れること」を技術構成の決め手にしている。**
その体制で、型を見きれないリンタを選ぶのは一貫しない。

## 決定

**`eslint` + `prettier` を採用する。`typescript-eslint` を型情報つきで有効にする。**

- `eslint` 10.8.0 / `prettier` 3.9.6
- `typescript-eslint` は型情報を要求する設定（プロジェクトの `tsconfig` を参照する構成）で使う
- `eslint-config-prettier` により整形規則の衝突を除く

Rust 側は [ADR-0018](0018-dependencies.md) のとおり `rustfmt` + `clippy`（警告をエラー扱い）のまま。

## 検討した選択肢

### 案 A: `eslint` + `prettier`（採用）

- 利点:
  - **型情報を使ったリントが完全に効く。** `await` 忘れ、`any` の不用意な伝播などを検出できる
  - 採用規模が大きい（`eslint` 1.53 億 DL/週、`prettier` 1.17 億 DL/週）
- 欠点:
  - 設定ファイルが増える（`eslint.config.js` / `.prettierrc` / `eslint-config-prettier`）
  - 型情報つきのリントは遅い

### 案 B: `biome`（ADR-0018 で採用、本 ADR で却下）

- 利点: 設定が 1 ファイル。10〜25 倍高速
- 却下理由: **型情報を要するルールの検出率が typescript-eslint に届かない**
  （`noFloatingPromises` で約 75%）。
  速度の利点は、本プロジェクトの規模では体感差にならない。
  **検出漏れは毎日効くが、設定の手間は一度きりである。**

## 決め手

**設定の手間を受け入れて、検出能力を取った。**

[ADR-0018](0018-dependencies.md) では判断軸を「設定の少なさ＝誤設定の起きにくさ」に置いたが、
これは軸の選択自体が誤りだった。**リンタは検出できるものの範囲で選ぶべきである。**

エージェントがコードを書き、人間が常時レビューしない体制
（[ADR-0003](0003-agent-driven-development.md)）では、
**コンパイラとリンタが最後の防波堤になる。** その防波堤を、設定の手間を理由に弱める判断は採らない。

## 影響

- [ADR-0018](0018-dependencies.md) のリンタの選定のみを置き換える。他の依存の決定は有効
- CI に型情報つきのリントを含めるため、実行時間が延びる
- 取り消す場合のコスト: 低（設定ファイルの入れ替えのみ）
