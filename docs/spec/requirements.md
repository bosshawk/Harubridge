# 要求仕様

> ステータス: **ドラフト（オーナー承認待ち）**
> ここに挙がっている要求は候補であり、確定していない。
> 承認された時点で本注記を外し、技術構成の検討に進む（[ADR-0004](../adr/0004-defer-tech-stack-decision.md)）。

## 記法

- ID は `FR-nnn`（機能要求）/ `NFR-nnn`（非機能要求）。**一度振った ID は再利用しない。**
- 優先度: `Must`（無いと成立しない）/ `Should`（あるべき）/ `Could`（あれば良い）
- 状態: `未確定` / `確定` / `対象外`
- 実装依頼とテストは、この ID を使って仕様を参照する。
