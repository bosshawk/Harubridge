# プロダクト概要

> ステータス: ドラフト（オーナー承認待ち）
> 承認されるまで、この文書を根拠に実装を開始しない（[ADR-0004](../adr/0004-defer-tech-stack-decision.md)）。

## 1. これは何か

`Harubridge` は、ブラウザゲーム「艦隊これくしょん」を快適にプレイするための
**専用ブラウザ（専ブラ）**である。

汎用ブラウザでのプレイに対して、以下の価値を提供する。

- ゲーム画面を適切なサイズ・位置で安定して表示する
- プレイ中に必要な情報（保有艦・装備・遠征や入渠の残り時間など）を、
  ゲーム画面を離れずに参照できる
- 手作業での記録・集計をなくす

## 2. 対象ユーザー

- PC でプレイする既存プレイヤー。
- 複数の外部ツールを併用しており、それらを 1 つにまとめたいと考えている層。
- 想定人数規模は「自分と身近な数人」。**大規模配布は当面の目標に含めない。**
  ソースは OSS として公開するが（[ADR-0005](../adr/0005-publish-as-oss.md)）、
  利用者数の拡大そのものは目標ではない。

## 3. スコープ

### やること

- ゲーム画面の表示と、表示まわりの操作（サイズ変更・スクリーンショット・音量など）
- ゲームとの通信内容を**読み取って**得られる情報の可視化
- 取得した情報のローカル保存と、時系列での参照

### やらないこと（非スコープ）

明確に対象外とするもの。要望があっても ADR で覆すまで実装しない。

| 非スコープ | 理由 |
| --- | --- |
| ゲームプレイの自動化・マクロ・巡回 | [constraints.md](constraints.md) の C-01 に反する |
| ゲームサーバへの追加リクエスト送信 | 同上。読み取り専用を貫く |
| 通信内容の改変・チート | 同上 |
| 取得データの外部サービスへの自動送信 | プライバシー方針。[constraints.md](constraints.md) C-04 |
| モバイル（スマートフォン）対応 | 当面の対象外。将来検討 |
| 多言語対応 | 日本語のみ |

## 4. 成功の条件

このプロジェクトが「うまくいった」と言える状態。

1. 汎用ブラウザに戻りたくならない程度に、表示と操作が安定している
2. 遠征・入渠・疲労といった時間管理を、アプリを見るだけで完結できる
3. 動作が原因でゲーム側に負荷や異常を与えていない
