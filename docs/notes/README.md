# 暫定メモ (notes)

**捨てる前提**で書く場所。調査ログ・思いつき・比較検討・保留中の論点。

ここに書かれた内容は**確定仕様ではない**。実装の根拠にしてはいけない。

## ルール

- ファイル名: `YYYY-MM-DD-english-kebab-topic.md`
- [`_template.md`](_template.md) をコピーして書く。冒頭の**状態ヘッダは必須**。
- 1 メモ 1 論点。長くなったら分ける。
- 結論を急がない。分からないことは「分からない」と書く。

## 状態

| 状態 | 意味 | 次にすること |
| --- | --- | --- |
| `進行中` | まだ検討中 | — |
| `昇格済み` | spec / ADR に反映済み | `archive/` へ移動 |
| `破棄` | 不要になった | `archive/` へ移動、または削除 |

## 昇格

メモの内容が固まったら、内容の性質に応じて移す。

| メモの内容 | 昇格先 |
| --- | --- |
| 案を比較して 1 つ選んだ | [`docs/adr/`](../adr/) に ADR を起票 |
| 実装が従うべき決まりごと | [`docs/spec/`](../spec/) を更新 |
| 手順・進め方 | [`docs/guides/`](../guides/) |

昇格したら、元のメモの状態ヘッダに**昇格先へのリンク**を書いてから `archive/` へ移す。
メモ本文は書き直さない（検討の跡として残す）。

## 棚卸し

`進行中` のまま 1 か月以上更新されていないメモは、見直して畳む。
点検には `.claude/skills/docs-audit` を使う。
