# ローカル専用のメモ置き場

> **このディレクトリの中身は git の管理対象外です**（この README を除く）。
> 置いたものは**コミットされず、他の人には共有されません**
> （[ADR-0015](../adr/0015-documentation-layout.md)）。

## 何を置くか

書き捨てて構わないもの。消えても困らないもの。

- 作業中の思考の整理、読んだコードのメモ、コマンドの控え
- Issue にする前の、まだ形になっていない断片

## 何を置かないか

**他人（将来の自分を含む）が読む必要があるものは置かない。**
共有されないため、ここに書くと失われたのと同じです。

| 内容 | 正しい置き場所 |
| --- | --- |
| 決めるべき論点・調査結果 | **GitHub Issue**（`gh issue create`） |
| 決定と却下案 | [`docs/adr/`](../adr/) |
| 仕様・基本設計 | [`docs/spec/`](../spec/) |
| 横断規約 | [`docs/guidelines/`](../guidelines/) |

判断基準はひとつ。**他人が読む必要があるか。**
あるなら Issue、無いならここ。迷ったら Issue に立ててください。

## 秘密情報について

git 管理外とはいえ、**提督名・認証情報・通信ログは置かないでください**
（[constraints.md](../spec/constraints.md) C-04 / C-07）。
誤って `git add -f` された場合、公開リポジトリの履歴に永久に残ります。
