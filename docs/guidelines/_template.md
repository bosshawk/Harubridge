## 原則

なぜこのガイドラインがあるのか。1 〜 3 文。
ルールを丸暗記させるのではなく、**判断の拠り所**を与える。

## ルール

ID は `G-<略号>-<連番>`。略号はこの文書に固有の 2 〜 4 文字の英大文字で、
[README.md](README.md) の一覧表で重複しないよう採番する（例: `logging.md` → `LOG`）。
連番は文書内で振り、**一度振った ID は再利用しない**。

強度を明示する。`MUST`（必須）/ `SHOULD`（原則そうする）/ `MAY`（してもよい）。

| ID | 強度 | ルール |
| --- | --- | --- |
| G-XXX-01 | MUST | |
| G-XXX-02 | SHOULD | |
