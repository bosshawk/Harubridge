# 計算式: 制空値

- 最終観測: 2026-08-02
- 確度: **一部未検証**（基本式は有志による検証済み。内部熟練度は「仮説」であり、資料間に差異がある）

対応する要求: [FR-031](../../spec/requirements.md)（制空値を計算して表示する、Must）、
[FR-014](../../spec/requirements.md)（基地航空隊の状態）、
[FR-035](../../spec/requirements.md)（敵艦の制空値）

> **計算式は非公開仕様の推定である。**
> [NFR-009](../../spec/requirements.md) により出典の併記が必須。
> 参照した有志 wiki 自身が、内部熟練度を「**内部熟練度仮説**」と呼んでいる。

## 何を求める式か

航空戦の冒頭で敵味方の**制空状態**（制空権確保／航空優勢／航空均衡／航空劣勢／制空権喪失）を
決めるために比較される値。艦隊・基地航空隊のそれぞれについて、
装備した航空機のスロットごとに求め、合算する。

**通常の艦隊で制空値に参加するのは、艦戦・艦攻・艦爆・水戦・水爆・陸戦（陸軍戦闘機）などの
戦闘機・攻撃機だけ**で、偵察機・電探・対空砲は影響しない。
**基地航空隊では偵察機（艦偵・水偵・陸偵・大型飛行艇）と陸攻も制空値を持つ**点が異なる。

## 式

### 通常の艦隊

```
制空値 = Σ_slot floor( (対空値 + 改修強化値) × √(搭載数) + √(内部熟練度 / 10) + 制空ボーナス )
```

- `[ ]`（floor）は**スロットごとに**適用し、その後に合計する。
- 搭載数が 0 のスロットは 0 とする。
- 「√(内部熟練度 / 10)」を**内部熟練ボーナス**、機種ごとの固定値を**制空ボーナス**と呼ぶ。
  有志 wiki が「熟練度補正 = 内部熟練ボーナス + 制空ボーナス」としているのがこれにあたる。

### 局地戦闘機（迎撃・対爆ステータス）

局地戦闘機は、対空値に加えて「迎撃」「対爆」のステータスを持つ。

```
出撃時 : 対空値 + 改修強化値 + 1.5 × 迎撃
防空時 : 対空値 + 改修強化値 + 迎撃 + 2 × 対爆
```

これを上式の `(対空値 + 改修強化値)` の位置に置く。

### 基地航空隊

```
航空隊の制空値(出撃) = floor( Σ_中隊 中隊の制空値(出撃) × 陸偵補正 )
  中隊の制空値(出撃) = floor( ((対空値 + 改修強化値) + 1.5 × 迎撃) × √(搭載数) + 熟練度補正 )

航空隊の制空値(防空) = floor( Σ_中隊 中隊の制空値(防空) × 偵察機補正 )
  中隊の制空値(防空) = floor( ((対空値 + 改修強化値) + 迎撃 + 2 × 対爆) × √(搭載数) + 熟練度補正 )
```

さらに、敵重爆撃機が入った空襲（高高度爆撃）に対しては、
**全航空隊の合計に**ロケット戦闘機の配置数による乗算補正がかかる。

### 変数

| 記号 | 意味 | 取得元 |
| --- | --- | --- |
| 対空値 | 装備の対空値 | 装備マスタ（`api_tyku`） |
| 搭載数 | そのスロットの現在の搭載機数 | 艦のデータ（スロットごとの搭載数） |
| 改修強化値 | 改修（★）による対空の上乗せ。下表 | 装備の改修レベル `★` |
| 内部熟練度 | 0 〜 120 の内部値。**直接は取得できない** | 装備の熟練度（0〜7）から範囲を推定 |
| 制空ボーナス | 熟練度と機種で決まる固定値。下表 | 装備の熟練度と機種 |
| 迎撃 | 局地戦闘機の「迎撃」ステータス | 装備マスタの回避欄（`api_houk`） |
| 対爆 | 局地戦闘機の「対爆」ステータス | 装備マスタの命中欄（`api_houm`） |
| 陸偵補正 / 偵察機補正 | 偵察機による航空隊全体の乗算補正。下表 | 配備している偵察機の種別と索敵値 |

### 内部熟練度と制空ボーナス

| 熟練度 | 内部熟練度 | 制空ボーナス（艦戦・水戦・陸戦・局戦） | 制空ボーナス（水爆） | 制空ボーナス（艦攻・艦爆・噴式機） |
| --- | --- | --- | --- | --- |
| +0（帯なし） | 0 〜 9 | 0 | 0 | 0 |
| +1 | 10 〜 24 | 0 | 0 | 0 |
| +2 | 25 〜 39 | +2 | +1 | 0 |
| +3 | 40 〜 54 | +5 | +1 | 0 |
| +4 | 55 〜 69 | +9 | +1 | 0 |
| +5 | 70 〜 84 | +14 | +3 | 0 |
| +6 | 85 〜 99 | +14 | +3 | 0 |
| +7（≫） | 100 〜 120 | +22 | +6 | 0 |

**基地航空隊で制空値を持つ艦偵・水偵・陸偵・大型飛行艇・陸攻の制空ボーナスは 0**
（内部熟練ボーナス `√(内部熟練度/10)` は付く）。

有志 wiki が別ページで挙げている「熟練度 MAX で艦戦・水戦は +25、水爆は +9、艦攻・艦爆は +3」は、
**この表の制空ボーナスに内部熟練ボーナスを足した合計**である
（22 + √12 ≒ 25.5、6 + √12 ≒ 9.5、0 + √12 ≒ 3.5）。同じ値の別表現であって、矛盾ではない。

### 改修（★）による強化値

| 係数 | 対象 |
| --- | --- |
| 0.20 × ★ | 艦戦・水戦・陸戦・局戦 |
| 0.25 × ★ | 爆戦（艦上戦闘爆撃機） |
| 0.5 × √★ | 陸攻・大型陸上機 |
| なし | 艦攻・水爆・爆戦以外の艦爆 |

### 偵察機による航空隊全体の乗算補正

**出撃時（陸偵補正）**

| 装備 | 索敵値 | 補正 |
| --- | --- | --- |
| 二式陸上偵察機 | 8 | 1.15 倍 |
| 二式陸上偵察機(熟練) | 9 | 1.18 倍 |

**防空時（偵察機補正）**

| 索敵値 | 水偵・飛行艇 | 艦偵 | 陸偵 |
| --- | --- | --- | --- |
| 9 以上 | 1.16 倍 | 1.3 倍 | 1.23 倍 ※資料に差異あり |
| 8 | 1.13 倍 | — | 1.18 倍 |
| 7 以下 | 1.1 倍 | 1.2 倍 | — |

補正は**配備している航空隊にのみ**適用される（第一航空隊に彩雲があるなら第一航空隊だけ）。
複数の偵察機がある場合の扱いについては「未確認のこと」を参照。

### 高高度爆撃に対する乗算補正（防空時）

| ロケット戦闘機の配置数 | 0 | 1 | 2 | 3 以上 |
| --- | --- | --- | --- | --- |
| 乗算補正 | 0.5 | 0.8 | 1.1 | 1.2 |

1 部隊に 3 個中隊まとめても、複数部隊に 1 個中隊ずつでも補正は同じ。
イベントの難易度丙以下では、配置数 1 枠以下でも補正が 1.0 に底上げされる。

## 適用条件

- **この式は「制空値」を求めるものであって、制空状態そのものではない。**
  制空状態は敵味方の制空値の比で決まる（下表）。
- **実際の戦闘結果としての制空状態は、ゲームが直接返してくる。**
  戦闘の応答に `api_kouku.api_stage1.api_disp_seiku` があり、
  `0=航空均衡 / 1=制空権確保 / 2=航空優勢 / 3=航空劣勢 / 4=制空権喪失`。
  **したがって制空値の計算は「出撃前の見積もり」にのみ必要**であり、
  戦闘後の表示にはゲームの返り値を使うほうが正確である。
- 判定の優先順は「航空戦未発生 > 敵制空値 0 > 敵索敵失敗 > 味方索敵失敗 > 通常判定」。
  味方が索敵に失敗すると制空権喪失になる。

| 制空状態 | 自軍に必要な制空値 |
| --- | --- |
| 制空権確保 | 敵艦隊合計制空値の 3 倍以上（または敵制空値 0 / 敵索敵失敗） |
| 航空優勢 | 1.5 倍以上 〜 3 倍未満 |
| 航空均衡 | 2/3 より大きい 〜 1.5 倍未満 |
| 航空劣勢 | 1/3 より大きい 〜 2/3 以下 |
| 制空権喪失 | 1/3 以下（または自艦隊索敵失敗） |

- 制空状態の決定後に撃墜された爆戦・水爆の数は、既に決まった制空権に影響しない。
- 基地航空隊と敵艦隊の制空判定では、**敵の水上偵察機も制空権争いに参加する。**
  敵が連合艦隊なら本隊・護衛部隊の双方が参加する。

## 既知の例外・未解明部分

**ここが本ページで最も重要な節である。** 制空値は「有志による検証で推定された式」であり、
実装によって値が食い違う部分がある。

### 1. 内部熟練度は取得できない。実装ごとに値が変わる

API から得られるのは**熟練度 0〜7 の段階だけ**で、内部熟練度（0〜120）は分からない。
そのため実装は「その段階のどの内部熟練度を使うか」を選ばざるを得ず、**結果が食い違う。**

| 実装 | 採り方 | 熟練度 +7 のときの内部熟練ボーナス |
| --- | --- | --- |
| ElectronicObserver | 区間の**下限**（オプションで上限も選べる） | √(100/10) = 3.16 |
| KC3Kai | 区間の**中央値**（`airPowerAverageBonuses`） | √(110/10) = 3.32 |
| （上限を採る場合） | 区間の**上限** | √(120/10) = 3.46 |

KC3Kai には「制空値が Poi / EO / KCV などと違う」という Issue（#2194）が実際に立っており、
**ツール間で表示が食い違うのは既知の現象**である。

**したがって「正しい 1 つの制空値」は存在しない。** 表示するなら、
どの採り方をしたかを明示するか、範囲（下限〜上限）で示すのが誠実である。

### 2. 熟練度 +1 の水爆の制空ボーナスで資料が食い違う

| 資料 | 熟練度 +1 の水爆の制空ボーナス |
| --- | --- |
| 有志 wiki「艦載機熟練度」 | 0 |
| KC3Kai（`airPowerTypeBonuses["11"]`） | 0 |
| ElectronicObserver（`SeaplaneBomber` の配列） | **1** |

2 対 1 で 0 が優勢だが、**黙って 0 を採らない。** 差があることを記録しておく。

### 3. 防空時の陸偵補正（索敵 9）で資料が食い違う

| 資料 | 索敵 9 の陸偵による防空補正 |
| --- | --- |
| 有志 wiki「基地航空隊」 | 1.23 倍 |
| ElectronicObserver（`1.12 + losrate × 0.06`） | **1.24 倍** |

他の値（水偵 1.1/1.13/1.16、艦偵 1.2/1.3、陸偵 索敵 8 で 1.18、
出撃時の陸偵 1.15/1.18、高高度の 0.5/0.8/1.1/1.2）は両者で一致している。
**索敵 9 の陸偵の防空補正だけが食い違う。**

### 4. KC3Kai にだけある改修係数

KC3Kai は次を持つが、ElectronicObserver にも有志 wiki の記述にも見当たらない。

- 大型飛行艇の対空改修係数 `0.15 × ★`
- 一部の装備（master id 486 / 487）で係数を `0.2 → 0.3`、`0.25 → 0.3` にする例外
  （ソースのコメントは 2023 年と 2025 年の検証ツイートを参照している）

**新しい検証を先に取り込んだのが KC3Kai なのか、KC3Kai 固有の判断なのかは判別できない。**

### 5. 装備ボーナスの扱いが未確認

艦娘と装備の組み合わせで発生する「装備ボーナス」が、
制空値の計算に使う対空値に含まれるかどうかを確認できなかった。
（有志 wiki は遠征の成功判定については「装備ボーナスを含む」と明記しているが、
制空値については記述を見つけられなかった。）

### 6. 敵の制空値は搭載数が分からない

敵艦隊の制空値は、敵の装備と**搭載数**が必要になるが、
搭載数は API から得られないことがある。KC3Kai は自前のデータで補っている。
**本プロジェクトで敵制空値（FR-035）を扱う場合、データの出所を別途決める必要がある。**
