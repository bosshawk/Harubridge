# 計算式

制空値・索敵値・攻撃力などの計算式を記録する。

書き方は [../README.md](../README.md) を参照。
**出典と観測日を必ず書くこと**（[C-03](../../spec/constraints.md)）。

計算式は [NFR-009](../../spec/requirements.md) により**出典の併記が必須**である。
「どの資料を正とするか」が割れた場合は、複数の出典を併記して差異を明記する。
