# ルール: 遠征・入渠・建造の時間

- 最終観測: 2026-08-02
- 確度: **参照**（有志 wiki と OSS 実装の突き合わせ。自前の実測はしていない）

対応する要求: [FR-020〜FR-027](../../spec/requirements.md)（時間管理・通知）

> 本ページの記述はすべて**観測に基づく推定**である（[C-03](../../spec/constraints.md)）。
> 根拠が確認できなかったものは `TODO(要検証)` として「未確認のこと」に分けてある。

## ルールの内容

### 共通: 完了時刻はゲームから絶対時刻で与えられる

遠征・入渠・建造のいずれも、**残り時間ではなく完了予定時刻が
UNIX 時刻（ミリ秒）として API に含まれる**。

| 対象 | フィールド | 備考 |
| --- | --- | --- |
| 遠征 | `api_deck` 各要素の `api_mission[2]` | `api_mission[0]` が状態、`api_mission[1]` が遠征 ID |
| 入渠 | `api_ndock` 各要素の `api_complete_time` | |
| 建造 | `api_kdock` 各要素の `api_complete_time` | |

遠征の状態 `api_mission[0]` は `0=未出撃 / 1=遠征中 / 2=遠征帰投 / 3=強制帰投中`。
これらのフィールドがどの応答に現れるかは
[api/api_port_port.md](../api/api_port_port.md) を参照。

有志 wiki は、遠征・入渠・建造のいずれについても
「PC の時計がサーバとずれていると完了時刻の表示が前後する」と注意している。
すなわち**ゲーム側の時刻はサーバ時刻（JST）で決まる**。

### 遠征

- **第 1 艦隊は遠征に出せない。** 遠征できるのは第 2 艦隊以降。
  第 3・第 4 艦隊の開放に伴い、同時に 2 部隊・3 部隊の遠征が可能になる。
  したがって**同時に出せる遠征は最大 3 件**である。
- 第 2 艦隊は任務 (A4)「6隻編成の艦隊を編成せよ！」のクリアで開放される。
- 同じ遠征に複数の艦隊を向かわせることはできない。
- 旗艦が大破していると遠征に出せない（随伴艦の大破は問題ない）。
- イベント期間中、連合艦隊を編成中の第 2 艦隊、遊撃部隊を編成中の第 3 艦隊は遠征できない。
- **遠征時間は遠征ごとに固定**で、マスタデータ `api_mst_mission` の `api_time`（分）で与えられる。
  艦隊の編成や結果によって変わらない。
- 遠征は**中止（帰還命令）できる**。中止した場合、実際に帰投するまでの時間は
  **「出発してからの経過時間」と「残り時間」の小さいほうを 3 で割った値**。
  中止は失敗として扱われ、資材・提督経験値・艦娘経験値はすべてゼロになる。
- 残り時間が 1 分を切っているとき、母港画面へ移動すると残り時間を待たずに完了する。

### 入渠

- **入渠ドックは初期 2 つ。課金アイテム「ドック開放キー」で最大 4 つまで拡張できる。**
  入渠ドックは修理専用で、建造で使う工廠ドックとは別枠。
- 修理には**時間**と**資材（燃料と鋼材）**が必要。
- **修理時間**（秒）:

  ```
  Lv 1〜11 : (Lv × 10) × 倍率 × 減少HP + 30
  Lv 12〜  : (Lv × 5 + a) × 倍率 × 減少HP + 30
      a = [ √(Lv - 11) ] × 10 + 50      ([ ] は小数点以下切り捨て)
  ```

  | 倍率 | 艦種 |
  | --- | --- |
  | 0.5 | 潜水艦・海防艦 |
  | 1.0 | 駆逐艦・軽巡洋艦・重雷装巡洋艦・練習巡洋艦・水上機母艦・潜水空母・揚陸艦・補給艦 |
  | 1.5 | 重巡洋艦・航空巡洋艦・高速戦艦・軽空母・潜水母艦 |
  | 2.0 | 低速戦艦・航空戦艦・正規空母・装甲空母・工作艦 |

- **修理費用**: `[艦ごとの修理係数] × [減少HP]`（端数切り捨て）。
  鋼材と燃料それぞれに係数がある。**艦のレベルは影響しない。**
  係数は艦種と改造状態で決まる（一覧は wiki の「入渠」を参照）。
- **ただし、修理時間と修理費用はゲーム側が艦ごとに配信している。**
  艦のデータに `api_ndock_time`（ミリ秒）と `api_ndock_item`（`[燃料, 鋼材]`）があり、
  ElectronicObserver はこれをそのまま読んでいる。上の式は
  **未入渠の艦について事前に見積もる場合や、値を検算する場合に使うもの**である。
- **高速修復材（バケツ）**を消費すると数秒で修理が完了する。
  **入渠の開始時・入渠中のどちらでも使用できる。** 保有上限は 3000。
  開始した入渠を中断する方法は無く、早く終わらせるには高速修復しかない。
- 修理時間が残り 1 分を切っている状態で入渠画面から別画面に移り戻ると完了する。
  また、空いているドックに別の艦を入渠させても完了する。
  最初から修理時間が 1 分以内の場合、入渠の瞬間に終わる。
- 入渠中の艦は、**出撃・演習・遠征・改装・装備の着脱ができない。**
  弾薬・燃料の補給、編成替え、補強増設スロットの付け外しは可能。
- **入渠の完了時、コンディション値が 40 未満なら 40 まで回復する**
  （[fatigue.md](fatigue.md) を参照）。

### 建造

- **建造時間は建造される艦ごとに固定**で、`00:17:00`（まるゆ）から
  `08:20:00`（Iowa）までの値を取る。投入資材のレシピは艦種の出やすさを変えるが、
  時間は「どの艦が建造されたか」で決まる。大型艦建造でしか出ない艦も同じ表に並ぶ。
- 建造完了後、**ドックをクリックして受け取るまで、どの艦かは判明しない。**
- **高速建造材**を消費すると待ち時間をスキップできる。
  **建造開始時と建造途中のどちらでも使用できる。**
  高速建造した枠は `api_complete_time` が 0 になり、`api_created_ship_id` が 0 以外になる。
- 建造完了まで残り 1 分を切っているとき、何らかの形で工廠が更新される
  （別のドックで建造を始めるなど）と、残り時間を待たずに完了する。

## 数値

| 項目 | 値 | 変動するか |
| --- | --- | --- |
| 同時に出せる遠征の数 | 最大 3（第 2〜第 4 艦隊） | 条件により変わる。第 3・第 4 艦隊が未開放なら 1 または 2 |
| 遠征の所要時間 | 遠征ごとに固定。`api_mst_mission.api_time`（分）で配信される | 固定（ゲームのアップデートで変わりうる） |
| 遠征中止から帰投までの時間 | `min(経過時間, 残り時間) ÷ 3` | 計算で決まる |
| 入渠ドックの数 | 初期 2、最大 4 | 条件により変わる（ドック開放キーの使用） |
| 入渠時間の下駄 | +30 秒 | 固定 |
| 修理時間の艦種倍率 | 0.5 / 1.0 / 1.5 / 2.0 | 艦種で決まる |
| 高速修復材の保有上限 | 3000 | 固定（2014/03/28 以降） |
| 建造時間 | 建造された艦ごとに固定。`00:17:00` 〜 `08:20:00` | 艦で決まる |
| 建造ドックの数 | `TODO(要検証)`。参照した OSS はいずれも 4 枠を前提にしている | 不明 |
| 残り 1 分未満での早期完了 | 遠征・入渠・建造のいずれにも存在する | 固定 |

> **数値を固定値として扱ってよいかは、別の問題である。**
> ゲームのアップデートで変わりうる（[C-03](../../spec/constraints.md)）。
> 実装がこの値をハードコードしてよいかは、ここではなく設計側で判断する。

## 変動の条件

- **遠征の枠数**は、第 3 艦隊・第 4 艦隊の開放状況で 1 〜 3 に変わる。
  加えて、イベント期間中に連合艦隊・遊撃部隊を編成していると、
  該当艦隊が遠征に出せなくなるため実質的な枠が減る。
- **入渠ドックの数**は課金アイテム「ドック開放キー」で 2 → 4 に増える。
  一度開放すると永続する。「ドック増設セット」（1000 ポイント）に
  ドック開放キー×1 が含まれる。
- **修理時間**は艦のレベルと減少 HP と艦種で変わる。
  **修理費用は艦のレベルによらない**（wiki が明記している）。
- **建造時間**は投入資材では変わらない。建造された艦で決まる。
